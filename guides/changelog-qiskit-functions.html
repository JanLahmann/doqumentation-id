Qiskit Functions

Juli 2026​

  • Pemeriksaan pre-flight baru dan metode backend baru di Qiskit Functions v0.17.0: Metode baru di qiskit-ibm-catalog memungkinkan Anda memeriksa kapasitas runtime dan akses backend sebelum menjalankan, dan run() sekarang memvalidasi keduanya sebelum mengirimkan job.

    • Apa yang baru

      • Saat Anda memanggil run() pada sebuah fungsi, layanan ini memeriksa tiga hal terlebih dahulu: apakah instance Anda memiliki kapasitas runtime, apakah Anda dapat menjangkau backend yang Anda sebutkan, dan apakah setidaknya ada satu backend yang tersedia. Jika ada yang salah, Anda akan langsung mendapatkan error yang jelas alih-alih menunggu di antrean.

        Anda juga dapat memeriksa sumber daya ini sendiri, kapan saja:

        • Periksa sisa kapasitas runtime Anda dengan usage().

        • Lihat daftar backend yang dapat dijangkau oleh instance Anda dengan backends().

        • Cari satu backend dan konfirmasi akses dengan backend().

        • Temukan backend dengan job tertunda paling sedikit dengan least_busy().

    • Kasus penggunaan umum

      • Periksa sisa kapasitas Anda sebelum menjalankan batch job yang panjang, dan lewati proses jika kapasitas tidak cukup untuk menyelesaikannya.

      • Pilih backend dalam kode alih-alih meng-hard-code sebuah nama.

      • Gagal dengan cepat (fail fast) di pipeline dan notebook alih-alih menunggu di antrean.

    • Mulai sekarang

      • Pertama, pastikan Anda menjalankan versi terbaru dari qiskit-ibm-catalog:

        pip install --upgrade qiskit-ibm-catalog

      • Kemudian lihat dokumentasi untuk informasi lebih lanjut dan contoh.

2025​

Kuartal ketiga

18 Juli 2025​

Template Qiskit Functions memberi Anda pipeline modular yang memungkinkan Anda menukar alat, metode, atau konfigurasi baru untuk eksperimen kustom Anda sendiri. Semua template fungsi juga siap untuk di-deploy ke Qiskit Serverless, di mana Anda dapat dengan mudah memanfaatkan komputasi klasik sebagai bagian dari menjalankan alur kerja Anda. Anda dapat men-deploy paket serverless Anda di lingkungan cloud pilihan Anda, atau memanfaatkan layanan hosted yang disediakan oleh IBM untuk pengguna Premium dan Flex Plan. Terlepas dari opsi mana yang Anda pilih, Qiskit Serverless membantu menyederhanakan eksekusi dan memparalelkan bagian dari alur kerja Anda.

Kunjungi panduan Template Qiskit Functions untuk mempelajari lebih lanjut, atau baca gambaran umum Qiskit Functions di dokumentasi.

Kuartal kedua

5 Juni 2025​

  • Kami dengan senang hati merilis dua fungsi baru untuk keuangan dan optimasi:

    • QUICK-PDE oleh ColibriTD memungkinkan pengguna menyelesaikan persamaan diferensial tertentu untuk masalah deformasi material dan dinamika fluida komputasi. Sebagai contoh, satu tim peneliti telah mulai menggunakan fungsi QUICK-PDE untuk mempelajari dinamika fluida reaktif baru yang dikembangkan untuk mentransfer panas lebih efisien dalam jenis reaktor nuklir yang dikenal sebagai Small Modular Reactors.

    • Quantum Portfolio Optimizer oleh Global Data Quantum memungkinkan peneliti keuangan kuantitatif melakukan back-test strategi optimasi portofolio. Berjalan pada lebih dari 100 qubit, fungsi ini menghitung rasio Sharpe portofolio dibandingkan pengembalian selama periode waktu tertentu. Pengguna awal sedang menjajaki kemampuan optimizer ini untuk mengevaluasi kinerja historis dari sebuah strategi investasi dan memungkinkan perbandingan berbagai portofolio dalam kondisi yang serupa.

Lihat Qiskit Functions Catalog untuk meminta uji coba gratis hari ini.

16 Mei 2025​

  • Selama beberapa minggu ke depan, setiap fungsi akan memberikan informasi rinci untuk membantu Anda menjalankan, men-debug, dan menganalisis alur kerja Anda. Ini termasuk:

    • Saat job gagal, Anda dapat menggunakan job.error_message() untuk menemukan kode error dan pesan spesifik guna membantu Anda men-debug alur kerja Anda

    • job.status() akan memberikan informasi lebih lanjut tentang apa yang sedang terjadi saat sebuah Function sedang RUNNING, termasuk:

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • Terakhir, setelah Qiskit Function selesai, Anda dapat memeriksa berapa banyak waktu yang dihabiskan di setiap tahap dengan job.result()['metadata']['resource_usage'], seperti pada contoh berikut.

Perluas untuk contoh kode
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
      },
    }
  }
}

Kami berharap perubahan ini membuat penggunaan Qiskit Functions lebih mudah, dan Anda dapat memulai dengan uji coba gratis di katalog hari ini.

2024​

16 September 2024​

  • Memperkenalkan pratinjau Qiskit Functions, untuk pengguna IBM Quantum Premium Plan. Untuk memulai, pip install qiskit-ibm-catalog dan jelajahi dokumentasi Qiskit Functions. Dengan klien Qiskit Functions Catalog, Anda dapat mengirimkan beban kerja ke layanan yang diabstraksikan yang dirancang untuk mempercepat riset Anda. Masuk dengan kredensial IBM Quantum Platform Anda yang sudah ada.

    Pratinjau Qiskit Functions Catalog memberikan akses kepada pengguna Premium Plan untuk menjelajahi fungsi yang tersedia, termasuk yang ditulis oleh IBM dan yang ditulis oleh anggota lain dari ekosistem kami. Katalog ini berisi dua jenis fungsi: fungsi circuit dan fungsi aplikasi.

    • Fungsi circuit menyediakan antarmuka yang disederhanakan untuk menjalankan circuit. Fungsi ini menerima circuit abstrak dan observable yang disediakan pengguna sebagai input, lalu mengelola sintesis, optimasi, dan eksekusi dari representasi ISA circuit. Fungsi circuit menggabungkan kemampuan terbaru dalam transpilasi, penekanan error, dan mitigasi error untuk membuat performa kelas utilitas dapat diakses langsung. Ini memungkinkan ilmuwan komputasi untuk fokus pada pemetaan masalah mereka ke circuit, alih-alih membangun pola untuk setiap masalah dari awal.

    • Fungsi aplikasi mencakup tugas tingkat lebih tinggi, seperti menjelajahi algoritma dan kasus penggunaan spesifik domain. Pengembang enterprise dan ilmuwan data mungkin tidak memiliki latar belakang pengetahuan ilmu informasi kuantum untuk bekerja dengan circuit, dan sebagai gantinya berharap dapat membawa pengetahuan domain mereka untuk memajukan algoritma dan aplikasi komputasi kuantum. Dengan fungsi aplikasi, pengguna dapat memasukkan input klasik mereka dan menerima solusi sehingga mereka dapat lebih mudah bereksperimen dengan menerapkan kuantum ke alur kerja spesifik domain mereka.

  • Dengan diluncurkannya Qiskit Functions Catalog, pengembang Premium Plan dapat menjelajahi IBM Circuit function. IBM Circuit function mencakup ekstensi Qiskit terbaru yang didukung AI untuk sintesis circuit, optimasi, dan penjadwalan, serta metode mitigasi error tingkat lanjut untuk mengembalikan estimasi seakurat mungkin dengan hardware saat ini.

    Pengguna dapat membeli lisensi untuk fungsi-fungsi berikut yang disumbangkan oleh mitra kami di Q-CTRL, QEDMA, dan Algorithmiq.

  • Fungsi circuit

    • Q-CTRL merilis fungsi circuit yang menerapkan teknik kontrol kuantum berbasis AI, dengan mana pengguna dapat berhasil menskalakan ke masalah yang lebih besar.

    • Algorithmiq merilis fungsi circuit yang menerapkan TEM (tensor-network error mitigation), sebuah metode mitigasi error untuk mendapatkan estimator dengan lebih sedikit shot dibandingkan metode PEC (probabilistic error cancellation).

    • QEDMA merilis fungsi circuit yang menggunakan protokol proprietary untuk karakterisasi operasi QPU yang berisik secara efisien dan akurat, dan menerapkan penekanan error serta mitigasi error berdasarkan data karakterisasi tersebut.

  • Fungsi aplikasi

    • Q-CTRL merilis solver optimasi dengan mana pengguna dapat memberikan sebuah graph atau objective, dan menerima biaya solusi.
